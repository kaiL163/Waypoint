# Проверки Waypoint — 26.09.2026

## Автоматические проверки

20 unit/API-тестов проходят локально. Изолированный estimate-режим в тестовом процессе; рабочий Docker использует OSRM. Проверены:

- baseline в исходном порядке;
- начало (не завершение) работ внутри окна;
- завершение последней работы до конца смены;
- срочная заявка при конфликте вместимости;
- навыки, транспорт, отменённые заявки, пустой набор;
- время события, сохранение начатой поездки/работы;
- недоступный инженер и повторный пересчёт на том же времени;
- дубликаты ID, недопустимые координаты, навыки и длительности;
- норматив без двойного учёта дороги;
- отсутствие eventTime, неизвестный ID, запрет отмены начатой заявки;
- HTTP 409 для устаревшей версии, HTTP 422 для неверного события;
- baseline не изменяет сохранённое состояние.

Production-сборки frontend прошли в Windows и Docker. Backend запускается в python:3.11-slim, PostgreSQL/PostGIS отвечает.

## Интеграция с настоящим OSRM

Команда python tests/check_stack.py внутри backend — read-only проверка без изменения текущего набора.

| Демо 5: 72 заявки / 12 инженеров | Базовый | OR-Tools |
|---|---:|---:|
| Назначено | 64 | 72 |
| Не назначено | 8 | 0 |
| Задействовано инженеров | 12 | 7 |
| Пробег, км | 247,03 | 76,99 |

Это измеренный результат синтетического демо с повторными адресами, не обещание такого улучшения на произвольных данных. Поиск ограничен временем; результат может различаться на другой машине. Для каждой остановки проверены окно, смена, навык, транспорт, уникальность и дорожная геометрия для car/walk/bike.

Один и тот же тестовый переезд: car — 6 мин / 3231 м, walk — 21 мин / 1719 м, bike — 11 мин / 1814 м. Профили действительно различаются, а не только меняют скорость на автомобильном пути.

На свежей БД загружено Демо 1, план построен кнопкой в UI. Через API проверены срочная заявка, отмена будущей заявки и недоступность инженера с разными eventTime. Возвращаются оба плана и полный список изменений. После перезапуска backend состояние сохранилось. В PostGIS подтверждены EPSG:4326 и история снимков.

## Интерфейс

- 1366×768: инженеры 250 px, заявки 450 px; drawer накладывается на карту.
- 1440×900: заявки 500 px, 72 компактные строки; нет горизонтального переполнения всей страницы.
- 390×844: нет переполнения страницы; прокрутка таблицы внутренняя, шапка sticky.
- Проверены поиск по ID, сортировка заголовком, детали заявки с объяснением, выбор инженера, сравнение по инженерам, пять демо в меню.
- В консоли браузера при этих сценариях ошибок не обнаружено.

## Оставшиеся ограничения

Общественный транспорт приблизительный, без GTFS/расписаний. Адреса без точных координат также приблизительные и помечены предупреждением. Нет живых пробок, GPS/фактического выполнения, авторизации и интерфейса восстановления истории. Допущение при событии: начатую поездку/ожидание/работу завершают, пересчитывается остаток.
