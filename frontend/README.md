# Waypoint — интерфейс

Полный запуск вместе с API, PostGIS и OSRM описан в [корневом README](../README.md). Для отдельной разработки интерфейса: `npm ci`, `npm run dev`; Vite проксирует `/api` на `http://localhost:8000`, поэтому backend должен быть запущен. Production-сборка: `npm run build`.

Демо-сценарии находятся в Москве. Выберите сценарий, нажмите «Построить план», затем откройте инженера или заявку, добавьте событие и сравните исходный план с оптимизированным. Демо-данные и планы сохраняются на сервере.

Загрузка поддерживает JSON с `{ "engineers": [...], "requests": [...] }` и CSV. Для CSV можно выбрать два файла с `engineer` и `request` в имени либо использовать столбец `entity` со значениями `engineer` / `request`. Координаты — WGS84 (`lat`, `lng`), время — `HH:MM`, навыки инженера в CSV разделяются `;` или `|`.
